# cnpso

This repository contains Java code for Particle Swarm Optimization (PSO). It was automatically exported from the Google Code project `cnpso`.

## Source layout

The `PSO/` directory contains the project. Java sources under `src/br/upe/poli/base/` include the `Algorithm`, `Problem`, and `Solution` abstractions used by the optimization code.

## Working with the project

Inspect the project files inside `PSO/` before choosing a build or IDE configuration. A compatible Java compiler and runtime are required. This root README does not establish a tested JDK version or a single build command; review the existing source and project metadata when restoring this legacy codebase.
